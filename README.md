# CSC4200_Programming_Assignment_2
  This project uses python sockets to create a client-server communication system as well as the struct library to create and unpack tcp headers

# Features
  Header and Payload logging \
  Simple setup through use of Makefile

# Requirements
  Python 3 \
  
# Setup and Installation
  clone this repository "git clone https://github.com/WJDenning/CSC4200_Programming_Assignment_2.git" \
  run server "make run-server" \
  run client "make run-client" \
  clean "make clean"

# Dependencies
  Socket python library for client server communication \
  Python struct library for header packing and unpacking \
  Logging library for message logging
